Кейс-задача № 3.

Дан одномерный массив A размерности N. Найти сумму отрицательных элементов,
расположенных между максимальным и минимальным элементами.

Принятые допущения:
  * "между" понимается строго: сами максимальный и минимальный элементы
    в сумму не входят;
  * если максимумов (минимумов) несколько, берётся первый из них;
  * порядок следования максимума и минимума в массиве может быть любым;
  * если между ними нет отрицательных элементов, сумма равна 0.
